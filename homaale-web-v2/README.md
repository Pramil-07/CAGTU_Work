Homaale is a platform designed to
provide service booking solutions to the
service seekers and business
opportunities to various service
providing companies by bridging a gap
between them. It covers a wide range of
services from various industries like
Accounting, Gardening, Health, Beauty,
and many more.

## Getting started
1. First, clone the project using following URLs:\
Using HTTPS:[ https://github.com/cagtu-nepal/homaale-web-v2.git]( https://github.com/cagtu-nepal/homaale-web-v2.git)\
Using SSH: [git@github.com:cagtu-nepal/homaale-web-v2.git](git@github.com:cagtu-nepal/homaale-web-v2.git)

2. Install the required packages and dependencies
```bash
yarn
# or
yarn install
```

3. Run the project development server
```bash
yarn dev
```
Now, the project will run on your local host with development server at `3005` port.

4. Run the project on production server
```bash
yarn build
#then
yarn start
```
Now, the project will run on your local host with development server at `8020` port.
